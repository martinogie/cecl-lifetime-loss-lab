# Limitations log

A running list of what the models and data do badly or can't do, who owns each issue, what reduces
its effect meanwhile, and when it will be fixed. Model validation (SR 11-7) expects one. It's filled
in throughout and must be current at the end of Phase 6. A limitation is never deleted: it is
closed, with the evidence.

**Impact** is the expected effect on the reserve: direction (overstates / understates / unclear) and
size (small / medium / large, or a number once measured).

## Closing an item

Record the date, what changed (with a link to the pull request or change-log entry) and the evidence
that the limitation no longer applies. Leave the row in place with status *closed*.
